
# CodeAlpha Basic Calculator

## Project Description
This project is a basic calculator developed using the C programming language as part of the CodeAlpha C Programming Internship.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Input validation
- Division-by-zero handling

## Concepts Used
- Variables and data types
- User input and output
- If-else statements
- Switch-case statements
- Arithmetic operators

## How to Compile
gcc calculator.c -o calculator.exe

## How to Run
.\calculator.exe

## Language
C
